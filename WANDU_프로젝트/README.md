# WANDU (완두) — 독서 완독 앱

종이책을 끝까지 읽게 돕는 앱. 조금 읽고 메모를 남기면, AI 친구 "완두"가 그 메모만 보고
질문해 주며 4페이지 고비를 넘기도록 돕는다.

- AI 질문·표지 글자 읽기는 이 링크(claude.ai)에서만 작동. 로컬 HTML로 열면 그 부분은 비활성.

## 폴더 안 파일
- **WANDU.html** — 최종 버전(네오 브루탈리즘 UI). 아래 기능 전부 포함.
- **독서완독웹_프로토타입.html** — 데스크톱 4단계 위저드 버전(중간 단계).
- **읽기친구완두_초기버전.html** — 모바일 채팅형 초기 버전.

## WANDU.html 주요 기능
- **홈(폴더 그리드):** 책마다 폴더 1개. 한 줄에 3개, 반응형. 헤더 `＋`로 새 폴더 생성.
- **표지 사진 → 제목·저자 자동 입력:** 표지 사진을 올리면 AI가 글자를 읽어 자동 채움(비전 가능 시).
- **메모 기반 대화:** 읽은 부분을 메모로 적으면 완두가 그 메모만 보고 질문 3개 → 이어서 채팅.
  - 할루시네이션 방지: AI는 책 원문을 모르고, "내가 적은 메모·답"에만 근거해 답함.
- **같은 책은 한 폴더에 누적:** 같은 제목으로 다시 시작하거나 "이어 읽기" 하면 기존 폴더에 쌓임.
- **정리(휴지통 아이콘):** 정리 모드에서 폴더 삭제(두 번 눌러 확인).
- **저장:** 모든 기록은 이 기기 브라우저(localStorage)에 저장. 다른 기기·사람과는 공유 안 됨.

## 한계 / 참고
- AI 기능은 보는 사람 계정에서 사용량이 나가고, 처음 쓸 때 동의 창이 뜰 수 있음.
- 비전(사진 글자 읽기)은 환경에 따라 안 될 수 있으며, 그때는 직접 입력으로 대체됨.
- 기록이 로컬 저장이라 브라우저 데이터를 지우면 사라짐. 여러 기기 공유가 필요하면 서버 저장으로 확장 필요.
